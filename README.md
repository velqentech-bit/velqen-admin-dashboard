# Velqen Admin Dashboard

Modern responsive admin dashboard UI built using HTML, CSS, JavaScript and Chart.js.

## 🚀 Features

- Responsive layout
- Sidebar navigation
- Multi-section switching (Dashboard, Users, Orders, Settings)
- Interactive sales chart (Chart.js)
- Dynamic content rendering
- Clean and structured code
- Modern UI design

## 🛠 Technologies Used

- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (Vanilla JS)
- Chart.js

## 📂 Project Structure

admin-dashboard/
│
├── index.html
├── css/
│   └── style.css
└── js/
    └── script.js

## 🎯 Purpose

This project was created as a portfolio demonstration of frontend dashboard development.

It simulates a real-world SaaS admin panel interface with navigation and analytics.
